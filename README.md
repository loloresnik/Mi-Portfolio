# Lorenzo Resnik — Portfolio

Portfolio personal bilingüe (español / inglés), desarrollado con HTML, CSS y JavaScript vanilla.

## Publicación con GitHub Pages

1. Entrá en **Settings → Pages** de este repositorio.
2. En **Build and deployment**, elegí **Deploy from a branch**.
3. Seleccioná la rama **main** y la carpeta **/ (root)**.
4. Guardá los cambios. GitHub va a publicar el sitio en:

   https://loloresnik.github.io/Portfolio-Progra2/

## Estructura

- `index.html`: contenido y secciones del portfolio.
- `styles.css`: diseño responsive y tema oscuro.
- `script.js`: selector de idioma y menú móvil.
