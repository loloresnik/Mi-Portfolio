# Lorenzo Resnik — Portfolio Web Personal

Portfolio web personal desarrollado para presentar mi perfil profesional, formación académica, conocimientos técnicos y proyectos en un solo lugar.

El sitio está disponible en español e inglés y cuenta con un diseño responsive, navegación interactiva y una interfaz visual de tema oscuro.

## 🌐 Demo

[Ver portfolio online](https://loloresnik.github.io/Mi-Portfolio/)

## 🎯 Objetivo del proyecto

El objetivo fue crear un espacio digital propio para mostrar mi recorrido como estudiante de Ingeniería Informática en UADE, compartir los proyectos en los que trabajé y facilitar el contacto profesional.

El portfolio reúne distintas secciones:

- **Inicio:** presentación personal y enlaces a mis perfiles.
- **Sobre mí:** breve descripción de mi perfil, intereses y objetivos profesionales.
- **Tecnologías y herramientas:** conocimientos de programación, sistemas operativos, ciberseguridad y herramientas de trabajo.
- **Proyectos:** muestra de trabajos académicos y personales, con enlaces a sus repositorios.
- **Formación:** estudios universitarios y formación complementaria.
- **Contacto:** medios para comunicarse conmigo por email, LinkedIn y WhatsApp.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño visual, tema oscuro, efectos, animaciones y adaptación responsive.
- **JavaScript:** selector de idioma español/inglés, menú de navegación para dispositivos móviles y elementos interactivos.
- **Git y GitHub:** control de versiones y administración del repositorio.
- **GitHub Pages:** publicación del sitio web.

El proyecto fue desarrollado con tecnologías web vanilla, sin utilizar frameworks ni bibliotecas de frontend.

## ⚙️ ¿Cómo se desarrolló?

1. **Planificación y estructura:** definí las secciones necesarias para presentar mi perfil, formación, habilidades, proyectos y datos de contacto.
2. **Maquetado:** organicé el contenido utilizando HTML5 y elementos semánticos.
3. **Diseño visual:** trabajé con CSS3 para construir una interfaz de tema oscuro, con una estética consistente y adaptable a diferentes tamaños de pantalla.
4. **Interactividad:** implementé con JavaScript el cambio entre español e inglés y el menú de navegación móvil.
5. **Integración de proyectos y enlaces:** incorporé accesos a repositorios, perfiles profesionales y medios de contacto.
6. **Publicación:** gestioné el código con Git y GitHub y publiqué el sitio mediante GitHub Pages.
